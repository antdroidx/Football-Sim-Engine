# Roster identity and CPU priority foundation

Builds on the existing `DepthChartService` scheme fit and shared `RosterPlanService`, adding:
- identity-derived positional priorities for Pro and College;
- identity-aware CPU draft and free-agent scoring in Pro;
- identity-aware recruiting/portal scoring in College;
- resource-aware pro acquisition scoring with priority + cap efficiency.

Remaining milestones:
- deeper cap/roster planning for extensions, cuts and trades;
- staff-adapted philosophy changes and UI display;
- long-term roster audits.
## Verification baseline
- Pro: 70 focused tests covering identity/depth/market/scouting/CPU movement and staff balance passed locally.
- College: 55 focused recruiting/portal/depth/roster tests passed locally.
